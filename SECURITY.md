# Security

This service is a speech I/O gateway for UnisonOS and is intended for local or tightly controlled deployments.

For overall security guidance (including how speech, wake-word, and “always-on” behavior are handled), see:

- https://project-unisonos.github.io/reference/security/

If you believe you have found a security issue in unison-io-speech, please follow the responsible disclosure guidance in the UnisonOS security docs or open a private security advisory on GitHub instead of filing a public issue.
